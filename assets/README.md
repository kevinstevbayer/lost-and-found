# Asset Specifications (`data.js` Source of Truth)

- **Helpers (`assets/helpers/HELPER_01..06.png`):** `192x192` PNG sheets (`6x6` grid of `32x32` frames, 8 fps, states: `idle`, `working`, `sleeping`, `happy`, `angry`, `leaving`).
- **Customers (`assets/customers/CUSTOMER_01..16.png`):** `160x160` static portrait PNGs.
- **Items (`assets/items/ITEM_01..12.png`):** `24x24` static PNGs.
- **Bosses (`assets/bosses/DAY_BOSS_01..08.png`), Rival (`assets/rival/RIVAL_01.png`), Upgrades, Skills, Modifiers, Events, Endings, Achievements, Clutter, Currencies, Tags, Choices, Meta:** `32x32` static PNGs.
- **UI Banners (`assets/ui/GAME_TITLE.png`, `LOCATION_01.png`):** `160x48` and `160x32` static PNGs.
- **Static Office Backdrop (`assets/ui/BACKGROUND_OFFICE.png`):** `320x180` pre-scaled static PNG.
- **Animated Strips (`assets/anim/GAMBLE_01..07.png`, `SCENE_A..G.png`):** `720x80` horizontal strips (`6` frames of `120x80`).
- **Animated Office Backdrop (`assets/anim/BG_OFFICE_01.png`):** `1920x180` horizontal strip (`6` frames of `320x180` at 5 fps).
